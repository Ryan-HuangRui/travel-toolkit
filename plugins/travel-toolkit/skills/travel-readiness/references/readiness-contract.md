# Readiness Contract

Each action must contain: action, reason, timing/deadline if known, evidence/source, and status `proposed`.

Useful categories include documents, health/insurance, payments/connectivity, transport, lodging access, venue preparation, luggage/gear, and destination-specific etiquette. Do not generate a generic packing list merely to fill space. Time-sensitive rules must be rechecked close to departure.

If an action affects a booking, visa, money, or safety, clearly distinguish official requirements from practical suggestions.
