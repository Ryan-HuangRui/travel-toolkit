# Travel Readiness

Read [the readiness contract](references/readiness-contract.md) before producing a brief.

1. Start with confirmed dates, transport, lodging, reservations, traveller constraints, and existing open tasks. Do not treat recommendations as booked facts.
2. Include only actions that have a concrete reason, owner, timing, or consequence. Separate `now`, `before departure`, and `carry / check on the day` when that improves actionability.
3. Mark every candidate action `proposed`. Summarize task candidates for the user; update `tasks.md` only after explicit confirmation.
4. Use primary sources for rules, visa, carrier, venue, or country-specific requirements. State a source's freshness and do not recycle expired information.
5. Return a local brief and structured proposed actions to Trip Buddy. Do not notify a group.
